Onde obter:

  1. Crie uma conta gratuita em brapi.dev.
  2. No painel da brapi, copie o seu token.
  3. Cole o token no campo Token da brapi. Os preços são buscados de novo na hora.

O token fica salvo só neste navegador e é enviado só para a brapi. Em outro aparelho ou navegador, cole de novo. Sem token, a brapi só responde alguns tickers de teste, como PETR4.
